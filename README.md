📚 **BrightLearn Data Analytics – Research Assignment 1**  
Foundations of Data Analytics & Data Science  

This repository contains my BrightLearn Data Analytics Research Assignment 1, which focuses on the foundational concepts, technologies, tools, ethics, and career pathways associated with Data Analytics and Data Science.  

The assignment is designed for beginner students and requires research-based answers written in the student's own words, supported by relevant sources, examples, and diagrams where appropriate.  

🎯 **Assignment Objective**    

The purpose of this research assignment is to develop a strong foundational understanding of:  

Data and database concepts  
Data analytics and data science  
Artificial Intelligence  
Machine Learning  
Deep Learning  
Natural Language Processing  
Large Language Models 
Generative AI  
APIs and developer concepts  
Cloud computing  
Version control  
Python and Jupyter Notebooks  
Data privacy and ethics  
Data governance  
AI bias  
Data and AI careers  
Business Intelligence  
The assignment contains 37 research and reflection questions covering these areas.  
📖 Assignment Sections  
Section A – Data Fundamentals  

This section introduces the fundamental concepts used in data management and analytics.  

Topics covered include:  

Database  
Data Warehouse  
Data Lake  
Data Mart  
Structured, Semi-Structured and Unstructured Data  
Data Modeling  
Data Mining  
Database Management Systems (DBMS)  
ETL – Extract, Transform, Load  
Data Storage Formats  

Examples of storage formats covered include:  

CSV  
JSON  
Parquet  
Avro  

The section also encourages research using reliable technology sources such as IBM, Google Cloud, AWS and Microsoft Azure.  

🤖 **Section B – Artificial Intelligence & Machine Learning**  

This section introduces Artificial Intelligence and the technologies that support modern AI systems.  

Topics include:  

Artificial Intelligence  
Artificial Intelligence (AI)

General AI / Strong AI  
Machine Learning  

The assignment covers the three main types of Machine Learning:  

Supervised Learning  
Unsupervised Learning  
Reinforcement Learning  
Other AI Concepts  
Deep Learning  
Neural Networks  
Natural Language Processing (NLP)  
Large Language Models (LLMs)  
Generative AI  
Training Datasets  
Computer Vision  

The assignment requires real-world examples of AI and its applications in everyday life.
